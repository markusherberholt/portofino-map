# Pickalbatros Portofino Marsa Alam – Free Interactive Guest Map

Free, unofficial and non-commercial interactive guest map for **Pickalbatros Portofino Marsa Alam, Egypt**.

**Open the map:** https://markusherberholt.github.io/portofino-map/

The map is intended to help new resort guests quickly find important places and information during their stay.

## Features

- Interactive resort map
- Restaurants, bars, pools, beach areas and Aqua Park
- Kids Club, sports, entertainment and guest services
- Opening hours and practical information
- Search by place, service or map number
- GPS position on the resort map
- Personal “Home” marker stored only locally in the browser
- Desktop and mobile support
- 7 languages: German, English, Italian, Russian, Polish, French and Spanish
